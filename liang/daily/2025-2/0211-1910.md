## 1910. Remove all occurrences of a substring
### C++
``` c++
class Solution {
public:
    string removeOccurrences(string s, string part) {
        // use c++ lib : s.substr() , erase
        int m = part.size();
        int output_size;
        string output="";
        for (int i=0;i<s.size();++i){
            output.push_back(s[i]);
            // output += s[i];
            output_size = output.size();
            if (part[m-1]==s[i] && output_size >= m){
                
                if (output.substr(output_size-m)==part) // substr(pos) : 從pos開始擷取substring到最後一個char
                    output.erase(output_size-m); // erase(pos) : 從pos開始刪除後面所有char
            }
        } 
        return output;
    }
};
// why using push back rather than "+"
// push_back : most cases O(1), 需要擴展時才要O(n), 
// output + s[i] 會創建新的 std:string 物件，將新的內容 copy ， 最後再指定給 output
// in my case : worse -> "a" "ab" "abc" ... 最壞導致 O(n^2) 時間複雜度
```
